## 三个入口

| 入口 | 位置 | 适合 |
|---|---|---|
| **侧栏图标** | 左侧图标条，插件/定时任务图标旁（帧+闪光图标） | 长时间连续出图，主区域空间大 |
| **会话头部 ✨** | 任意对话右上角的闪光按钮 | 边聊边生成，不离开当前上下文 |
| **抽屉** | 点上面那个按钮后，从右侧滑出 | 快速试几次；`Esc` 或点遮罩关闭 |

三个入口渲染的是同一个组件，所以功能和数据完全一致。

### 只保留一个入口

两个入口在**插件详情页**里有开关：

> 设置 → 插件 → 找到 **Agnes Media Studio** → 详情页里的「入口开关」区域

| 开关 | 控制什么 |
|---|---|
| **侧栏工作台** | 左侧图标条里的 ✦ 图标，以及对应的工作台页面 |
| **会话内抽屉** | 对话头部的 ✨ 按钮，和从右侧滑出的抽屉 |

开关写入宿主文件 `~/.dsh/agnes-media/entries.json`，刷新和重启后保持。

关掉某个入口后，它对应的 slot 注册会被**完全移除**（不只是隐藏），不留 DOM 和监听器。

> 关掉抽屉不影响「发送到对话」—— 会话通道由另一个 session 作用域的注册提供，
> 与按钮是否可见无关。

## 生成图片

1. 选「**图片**」标签
2. 输入提示词
3. 选**宽高比**（每个 chip 带比例缩略框）和**尺寸**
   - 标签右侧实时显示实际像素，例如 `16:9 · 1K → 1312×736`
4. 点「生成」或 `Ctrl/⌘ + Enter`

### 尺寸 × 宽高比 → 像素

| 比例 | 1K | 2K | 3K | 4K |
|---|---|---|---|---|
| 1:1 | 1024×1024 | 2048×2048 | 3072×3072 | 4096×4096 |
| 3:4 | 864×1152 | 1728×2304 | 2592×3456 | 3456×4608 |
| 4:3 | 1152×864 | 2304×1728 | 3456×2592 | 4608×3456 |
| 16:9 | 1312×736 | 2624×1472 | 3936×2208 | 5248×2944 |
| 9:16 | 736×1312 | 1472×2624 | 2208×3936 | 2944×5248 |
| 2:3 | 832×1248 | 1664×2496 | 2496×3744 | 3328×4992 |
| 3:2 | 1248×832 | 2496×1664 | 3744×2496 | 4992×3328 |
| 21:9 | 1568×672 | 3136×1344 | 4704×2016 | 6272×2688 |

> 2.5 系列**每次只出 1 张**，所以面板没有数量选择器。

## 图生图与多图合成

在「图片」标签下有「**参考图**」区域：

1. **拖入图片**，或点击虚线框选择文件（支持多选）
2. 最多 **5 张**；每张显示缩略图，点 `✕` 移除
3. 提示词描述你想要的改动，例如「把这只猫换成水彩画风格」「把这三张合成一张海报」
4. 生成

### 实现细节（为什么快）

- 本地文件自动转成 **data URI** 内联发送，不需要图床、不需要公网地址
- 超过 1.5 MB 的图片会先**等比缩到长边 2048px** 再编码：
  - 参考图只是条件输入，不需要全分辨率
  - base64 会膨胀约 4/3，不缩放会撞上宿主 32 MiB 的请求体上限
- 单文件硬上限 24 MB，超出直接提示而不是发一个必然失败的请求

### 更快的路径：用历史结果当参考图

在任意图片卡片的操作栏点「**作为参考图**」，它会：

1. 拉取那张图的远程地址
2. 内联成 data URI 放进参考图区
3. 自动切回「图片」标签

于是「生成 → 满意 → 基于它做个变体」不需要下载再上传。

## 生成视频

1. 选「**视频**」标签
2. 选**模式**：

| 模式 | 用途 | 需要填 |
|---|---|---|
| **文生视频** | 纯文字描述 | 只填提示词 |
| **首尾帧** | 指定起止画面 | 首帧 / 尾帧 URL（至少一个） |
| **参考素材** | 按参考图/音频生成 | 图片 URL ≤5 张、音频 URL ≤3 段；提示词里用 `<Picture 1>` `<Audio 1>` 指代 |
| **提示词一步流** | 没有公共素材地址时首选 | 关键帧提示词（留空则用主提示词） |

3. 选宽高比与时长（**4–12 秒**）
4. 生成 → 排队 → 渲染 → 完成，卡片上有进度条

### 约束（网关强制，插件已在提交前校验）

- 分辨率固定 **720P**（Flash 模型只接受这个值，传其他值返回 400）
- 模式与媒体字段**互斥**：
  - `text` 不能带任何媒体
  - `keyframe` 不能带参考图/音频
  - `reference` 不能带首尾帧
- 参考图最多 5 张、参考音频最多 3 段

> 这些校验都在**建任务之前**完成，失败不产生费用。

## 结果卡片

每张卡片右下角的操作：

| 按钮 | 作用 |
|---|---|
| **打开** | 新标签页打开远程地址 |
| **本地文件** | 复制本地落盘路径 |
| **复制提示词** | 一键复制 |
| **复用参数** | 把提示词 + 尺寸/宽高比/模式填回表单 |
| **作为参考图** | 图片专属：内联为参考图，用于图生图 |
| **发送到对话** | 把结果发进当前对话（仅在有会话绑定时出现） |
| **重试** | 用原参数重跑 |
| **继续** | 仅「已中断」的视频任务：接着轮询，**不重新建任务** |
| **删除** | 从历史移除 |

### 卡片状态

| 状态 | 含义 |
|---|---|
| 排队中 | 已提交，等待执行 |
| 生成中 / 渲染中 | 执行中，带进度条 |
| 完成 | 有 URL 可打开 |
| 失败 | 卡片上直接显示原因 |
| 已中断 | 宿主重启导致，可「继续」 |
| 触发限流 | 自动重试中，显示倒计时 |

卡片右上角的「**来自对话**」标记表示这是你在聊天里让 AI 生成的。

## 与 AI 对话联动

### 面板 → AI

在面板调好一张图，点「发送到对话」，然后直接说：

```
把这张图做成 5 秒视频，镜头缓慢推近
```

### AI → 面板

在对话里说「用 Agnes 生成一张…」，结果会**自动出现在面板历史**，标「来自对话」，可以复用参数或再发回对话。

### AI 读取面板历史

```
看看我刚才在 Agnes 面板生成了什么，把最新那张做成视频
```

AI 会调用 `agnes_media_history` 工具，查到精确的 prompt / 参数 / URL，直接拿去当首帧，不用你复述。

该工具支持按 `kind`（image/video）、`source`（panel/agent）、`promptContains` 过滤。

### 关于「发送到对话」的可用性

- **抽屉**：通过会话作用域子槽拿到当前会话，始终可用
- **页面版**：从主视图快照解析当前会话
- 两者都拿不到时**不显示**该按钮，而不是给一个会失败的按钮

## 免费额度与限流

Agnes 免费档按分钟限流。触发时**不需要手动干预**：

1. **HTTP 层**：`429` 按 6s → 15s → 30s 退避重试
2. **任务层**：仍失败则任务自动重新排队（15s → 45s → 90s，最多 3 次），卡片显示「N 秒后重试」
3. 三次都失败才标记为「失败」，此时可手动点「重试」

### 任务不会丢

任务跑在**宿主进程**，不在浏览器里：

- 关面板、刷新页面 → 进度继续
- 重启 DSH → 中断的任务标记「已中断」，点「继续」接着轮询
- 视频任务保留服务端 `videoId`，**继续不会重复建任务**，不会重复计费

任务库位置：`C:\Users\Administrator\.dsh\agnes-media\jobs.json`（可用 `storeDir` 配置改）

## 常见问题

**Q：提示「未配置 API Key」怎么办？**

三种方式任选：

1. 在 DSH 设置 → 模型 → 凭据里加 `AGNES_API_KEY`
2. 设环境变量 `AGNES_API_KEY`
3. 在 `cordis.patch.yml` 里填 `apiKey`

Key 在 <https://platform.agnes-ai.cn> → API Keys 免费创建。

**Q：为什么参考图区没有出现？**

参考图只在「图片」标签下。视频的参考素材走「参考素材」模式，填的是 URL 而不是上传文件（视频 API 不接受 data URI）。

**Q：上传的图片会传给谁？**

只发给 Agnes 网关（`api.agnes-ai.cn`），并且走宿主代理，浏览器不持有 API Key。

**Q：图片和视频存在哪？**

- 远程：Agnes CDN，有有效期
- 本地：若配置了 `downloadDir` 则落盘；卡片上的「本地文件」按钮可复制路径

**Q：面板历史和对话历史是同一份吗？**

不是。面板历史是插件的任务库；对话历史是会话日志。两者通过「发送到对话」和工具记录互通。

**Q：一次能跑几个任务？**

面板同一时间只显示一个进行中任务并禁用生成按钮。但任务库可以保存多个历史，Agent 工具调用也不受面板按钮限制。
